# Submission checklist

- [ ] Create and activate the virtual environment.
- [ ] Install requirements with `pip install -r requirements.txt`.
- [ ] Run `python train_models.py` and review the printed scores.
- [ ] Run `python app.py`; test both dataset tabs and prediction forms.
- [ ] Run `python gradio_app.py`; test both prediction tabs.
- [ ] Read the Word report and fill in instructor/date if required.
- [ ] Take screenshots of the running interfaces if your instructor asks.
- [ ] Create your own GitHub repository and replace the sample remote URL in README.
- [ ] Make sure you can explain the model, preprocessing, train/test split, MAE, RMSE, and R².
- [ ] Tell your instructor that the bundled datasets are synthetic practice data.
